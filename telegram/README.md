Новая версия серверного `api/lead.php`, сохраняющая заявки в общую Google-таблицу, пока **только в GitHub; на Beget не проверена**. Действующее VK Mini App **54772740** не меняется.

**Целевой адрес развёртывания согласован:** `https://ceilingzamer.ru/aspeckor/`.
Содержимое папки репозитория `telegram/` должно лежать прямо в веб-каталоге `/aspeckor/`, то есть `telegram/index.html` → `https://ceilingzamer.ru/aspeckor/index.html`, `telegram/app.js` → `.../aspeckor/app.js`, `telegram/api/lead.php` → `.../aspeckor/api/lead.php`. **Не размещайте лишний уровень `/aspeckor/telegram/`.**

**Единая таблица заявок:** `VK Mini App - заявки калькулятора загрузки` (Google Sheets ID `1z618hByqrMG8Z_pD7kQ4vD740qLh8fBVTgWGKLaj7fE`). Telegram-обработчик передаёт заявку в **тот же Google Apps Script**, который уже использует VK Mini App. Существующий `doPost(e)` менять не требуется. Дополнительный Telegram-чат и идентификатор чата не нужны.

**Важно:** изменения сохранены в GitHub, но новая версия обработчика и политики **ещё не загружена на Beget**. Пока не подтверждено сохранение реальной заявки, публикацию рекламных ссылок отложить.

## Источник
Перенос из актуального `index.html` на ветке `main` репозитория `vk-team-load-calculator` (не из устаревшего корневого `app.js`).

## Состав
- `index.html`: сохранён дизайн VK-калькулятора и переходы 1–2–3 шага → результат → контакт.
- `app.js`: существующие коэффициенты и расчёт (24/44/67/83 заказов, 70% замер→заказ, 33% обращение→замер, 14.5% просмотр→обращение), только Telegram SDK; отдельной новой модели не придумано.
- `api/lead.php`: проверяет подлинность `Telegram.WebApp.initData` на сервере, валидирует заявку и записывает в общую Google-таблицу **через существующий Apps Script**, с явной проверкой ответа `{success:true}`; не показывает ложный успех при HTTP 200 с ошибкой или при недоступности Google.
- `privacy-policy.html`: описание Telegram-канала обработки данных.

## Деплой
1. Разместить **содержимое** папки `telegram/` в `/aspeckor/` на Beget (**HTTPS, PHP 8.1+ и cURL**), не затрагивая действующий сайт, VK Mini App и контент-воркфлоу. Размещение на Beget через эту GitHub-ветку автоматически не происходит.
2. Настроить секрет Telegram **без публикации токена**:
   - В Beget на уровне **каталога сайта** (рядом с `public_html`, НЕ внутри него) создать файл `aspeckor-secrets.php` из шаблона `aspeckor-secrets.example.php`.
   - Внутри приватного файла заменить `PASTE_BOTFATHER_TOKEN_HERE` на реальный токен `@Aspeckor_bot` из @BotFather. **Не передавать токен в чат, GitHub, скриншоты и браузерные URL.**
   - Веб-путь должен остаться `/aspeckor/api/lead.php`; обновить этот файл в Beget из GitHub после коммита о поддержке приватной конфигурации.
   - `api/lead.php` проверяет `ASPECKOR_BOT_TOKEN` в окружении, а при его отсутствии считывает `aspeckor-secrets.php` из **родительской папки фактического webroot** (по `DOCUMENT_ROOT`). Поэтому при нестандартной конфигурации Beget нужно сверить реальный каталог сайта с `DOCUMENT_ROOT`.
   - Другие секреты для Google-таблицы не нужны: используется действующий URL Google Apps Script из VK Mini App.
   - **Не загружать файл с настоящим токеном в `public_html`, `aspeckor/` или `api/`.** Если расположить его вне webroot не удаётся, не подставлять токен в `lead.php` — сначала согласовать способ хранения.

3. **Main Mini App** `@Aspeckor_bot` уже привязан к `https://ceilingzamer.ru/aspeckor/`; интерфейс открылся на устройстве пользователя (13 октября 2026).
4. Только после развёртывания и проверки подтверждённой доставки заявки использовать ссылки:
   - YouTube: `https://t.me/Aspeckor_bot?startapp=yt`
   - Instagram: `https://t.me/Aspeckor_bot?startapp=ig`
   - Telegram: `https://t.me/Aspeckor_bot?startapp=tg`

## Быстрая проверка после настройки секрета
1. Открыть Mini App из `@Aspeckor_bot` и сделать тестовый расчёт.
2. Отправить одну **тестовую** заявку со своими контактами и временем звонка.
3. Убедиться, что приложение показало успех и в существующей таблице появилась новая строка с `Источник = Telegram / прямой переход`, либо `YouTube`/`Instagram` при ссылке с `startapp`.
4. При ошибке не копировать токен, а сообщить только код ответа `SERVER_NOT_CONFIGURED`, `INVALID_SIGNATURE`, `SHEETS_SAVE_NOT_CONFIRMED` и т.д. Успешное открытие `index.html` ещё не доказывает работу PHP.
5. Для привязки источников использовать ссылки `https://t.me/Aspeckor_bot?startapp=yt`, `?startapp=ig`, `?startapp=tg`. Отображаемые результаты расчёта при этом не меняются.

## Перед запуском рекламы
- Проверить открытие в Telegram, расчёт 1/2/3/4/5+ бригад, валидацию телефона/даты и явное согласие.
- Проверить реальную запись в Google-таблицу и что приложение не показывает экран «Отправлено» при ошибке.
- Проверить `start_param` из 3 ссылок и серверную верификацию Telegram initData.
- Отдельно проверить правдивость коэффициентов и текста «средние показатели наших клиентов». **Город в калькуляторе пока только сохраняется: локального анализа спроса не происходит.**
- **Единая база заявок:** код `api/lead.php` уже адаптирован под тот же 16-колоночный формат существующей таблицы (включая «Источник», «Кампания», «Объявление», «UTM / параметры входа», «Полная входная ссылка»). **Фактическая запись на Beget ещё не проверена**, пока файл не обновлён и секрет Telegram недоступен PHP. Существующий Google Apps Script и таблица не редактировались.
- Мониторинг конверсий по промежуточным этапам, idempotency/защита от повторных отправок, дополнительное Telegram-уведомление и интеграция n8n — возможные отдельные доработки; **не нужны** для базовой записи в общую таблицу. При потере ответа Google возможна повторная запись, если пользователь повторит отправку — это известное ограничение `appendRow` без idempotency.

## Ограничения
Telegram Mini App загружается с внешнего HTTPS-хостинга **внутри Telegram**, а не хранится на серверах Telegram. Наличие Telegram/VPN не гарантирует доступность выбранного хостинга при сетевых ограничениях.

Ни бот, ни сайт, ни API не развёрнуты через один GitHub-коммит. Для выпуска нужны работающий URL, серверная конфигурация и настройки BotFather.
