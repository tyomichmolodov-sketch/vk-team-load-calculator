# Асpeckor — Telegram Mini App: расчёт загрузки бригад

Статус: **подготовлено в отдельной feature-ветке, НЕ развёрнуто**. Действующее VK Mini App **54772740** не меняется.

## Источник
Перенос из актуального `index.html` на ветке `main` репозитория `vk-team-load-calculator` (не из устаревшего корневого `app.js`).

## Состав
- `index.html`: сохранён дизайн VK-калькулятора и переходы 1–2–3 шага → результат → контакт.
- `app.js`: существующие коэффициенты и расчёт (24/44/67/83 заказов, 70% замер→заказ, 33% обращение→замер, 14.5% просмотр→обращение), только Telegram SDK; отдельной новой модели не придумано.
- `api/lead.php`: проверяет подлинность `Telegram.WebApp.initData` на сервере, валидирует заявку и доставляет в приватный чат через Bot API; успех отдаёт **только после подтверждения Telegram**, в отличие от старого no-cors/webhook.
- `privacy-policy.html`: описание Telegram-канала обработки данных.

## Деплой
1. Разместить всю папку `telegram` на **HTTPS-хостинге с PHP 8.1+ и cURL**, например в отдельном пути Beget, не затрагивая существующие VK/VK ID/контент-воркфлоу.
2. Настроить серверные секреты **ВНЕ репозитория и вне public webroot**:
   - `ASPECKOR_BOT_TOKEN` — токен `@Aspeckor_bot`, только серверная переменная окружения.
   - `ASPECKOR_LEADS_CHAT_ID` — личный чат владельца бота (предварительно нажать /start в @Aspeckor_bot) или админ-чат, где бот умеет писать.
   - Не размещать токен в JS, публичных `.env`/PHP-файлах или GitHub. Если хостинг не передаёт env в PHP, сначала согласовать закрытое серверное хранилище и механизм загрузки секретов.
3. После появления рабочего HTTPS URL настроить **Main Mini App** в @BotFather для `@Aspeckor_bot` (не путать только с Menu Button). При необходимости настроить Menu Button «Рассчитать загрузку» на тот же URL.
4. Только после развёртывания и проверки подтверждённой доставки заявки использовать ссылки:
   - YouTube: `https://t.me/Aspeckor_bot?startapp=yt`
   - Instagram: `https://t.me/Aspeckor_bot?startapp=ig`
   - Telegram: `https://t.me/Aspeckor_bot?startapp=tg`

## Перед запуском рекламы
- Проверить открытие в Telegram, расчёт 1/2/3/4/5+ бригад, валидацию телефона/даты и явное согласие.
- Проверить реальный приватный чат получает заявку и что в приложении нет ложного экрана «Отправлено» при ошибке.
- Проверить `start_param` из 3 ссылок и серверную верификацию Telegram initData.
- Отдельно проверить правдивость коэффициентов и текста «средние показатели наших клиентов». **Город в калькуляторе пока только сохраняется: локального анализа спроса не происходит.**
- Мониторинг конверсий по этапам и подключение Google Sheets/n8n — отдельная доработка. В этой ветке они не включены, чтобы не ломать рабочие процессы.

## Ограничения
Telegram Mini App загружается с внешнего HTTPS-хостинга **внутри Telegram**, а не хранится на серверах Telegram. Наличие Telegram/VPN не гарантирует доступность выбранного хостинга при сетевых ограничениях.

Ни бот, ни сайт, ни API не развёрнуты через один GitHub-коммит. Для выпуска нужны работающий URL, серверная конфигурация и настройки BotFather.
